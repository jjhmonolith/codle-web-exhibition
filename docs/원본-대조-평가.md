## 1. 총평

수정 전 재현본은 **텍스트 카피와 섹션 순서는 대체로 맞았지만, 디자인 언어 자체가 다른 사이트**였다.
원본은 "화이트 + 밝은 블루(#3E88FF) 포인트, 여백 큰 미니멀" 톤인데, 재현본은
"크림 배경(#FDFCFA) + 보라(#6B4EE6) + 다크 카드(#17151E)" 톤으로 재해석되어 있었다.

| --- | --- | --- |
| 정보 구조 / 섹션 순서 | 85% | 100% |
| 카피(문구) | 90% | 99% |
| 컬러 / 타이포 | 20% | 95% |

## 7. 단순화 (최종 반영)

원본을 그대로 따라가니 인터랙션·애니메이션이 과다해 버그 표면이 넓어졌다.
**정보 구조와 시각 언어는 그대로 두고, 움직이는 것들을 걷어냈다.**

### 7.1 제거한 것

| 대상 | 이전 | 이후 | 이유 |
| --- | --- | --- | --- |
| 히어로 헤드라인 | 148px 무한 가로 마퀴(카피 2벌 중복) | **92px 고정 2줄** | 가로 오버플로 위험, 모바일에서 중복 카피를 CSS로 숨기는 취약한 구조 |
| 스크롤 리빌 | `requestAnimationFrame` 무한 루프 + `opacity:0.001` 초기값 | **제거** | JS 실패 시 본문이 통째로 안 보이는 사고 유형 제거 |
| 스크롤 스파이 | 위 rAF 루프에 동거 | **passive 스크롤 리스너 + rAF 1프레임 스로틀** | 상시 루프 제거, 언마운트 시 리스너 해제 |
| 3D 오브젝트 8개 | `floaty` 부유 애니메이션 | **정지** | 대형 이미지 상시 애니메이션 부담 |
| 스크롤 힌트 셰브론 | `bounceDown` 반복 | **정지** | |
| AI 말풍선 띠 | 4벌 복제 + 무한 마퀴 | **말풍선 1개 중앙 정렬** | |
| 맞춤학습 원형 배지 ×3 | SVG `textPath` + 회전 | **가로 텍스트 라벨** | 회전을 멈추니 판독 불가 → 애초에 정보 전달이 목적인 요소 |
| `@keyframes` | 4종 | **0종** | |

검증: 전 뷰포트에서 `animationName !== 'none'` 인 노드 **0개**.

### 7.2 되살린 것

단순화 후 검토에서 히어로가 너무 밋밋해져, **히어로 한정으로 원래 애니메이션을 복구**했다.

- 헤드라인 148px 무한 가로 마퀴. 모바일은 40px 2줄 고정으로 마퀴 정지
- 3D 오브젝트 6개 부유 애니메이션
- 스크롤 힌트 셰브론 상하 바운스

`@keyframes`는 `marqueeL` / `floaty` / `bounceDown` 3종만 남았다.
해결 섹션의 지구본·모니터 일러스트, AI 말풍선 띠, 맞춤학습 배지는 정지 상태를 유지한다.

## 8. 최종 인터랙션 설계

### 8.1 CSS만으로 처리 (JS가 죽어도 무해)

| 대상 | 동작 |
| --- | --- |
| 상단 내비 | 비활성 항목에만 hover 배경. 활성 여부는 `data-on` 바인딩으로 CSS에 전달 |
| 체험하기 버튼 | hover 시 배경 연블루 + 테두리 진하게 + 2px 상승, active 시 눌림 |
| AI 캐러셀 화살표 | hover 시 1.12배 + 배경 블루, active 시 눌림 |
| AI 캐러셀 도트 | hover 시 연블루 |
| 해결 섹션 칩 | hover 시 3px 상승 + 그림자 강화 |
| 수업 미디어 | 항목 hover 시 1.02배 + 그림자 |
| AI 카드 | hover 시 테두리·그림자·2px 상승 |
| 전 요소 | `:focus-visible` 포커스 링. 마우스 클릭에는 안 뜨고 키보드 탐색에만 |
| 전 요소 | `prefers-reduced-motion: reduce` 시 모든 애니메이션·트랜지션 정지 |

hover 효과는 전부 `@media (hover: hover)`로 감쌌다. 모바일에서 탭 후 hover 상태가 남는 문제를 막는다.

### 8.2 JS 인터랙션

| 대상 | 구현 |
| --- | --- |
| 스크롤 스파이 | passive 스크롤 리스너 + rAF 1프레임 스로틀 |
| 스크롤 리빌 | 같은 스크롤 핸들러에 얹음. 대상이 화면 92% 지점에 닿으면 fade-up, 형제끼리 70ms 순차 지연 |
| AI 캐러셀 | 좌우 화살표, 도트, **키보드 좌우 방향키**, **모바일 좌우 스와이프** |
| 영상 | 마운트·갱신 시 명시적 재생 |

리빌은 `IntersectionObserver`를 쓰지 않았다. 앵커 점프처럼 한 번에 여러 화면을 건너뛰면
지나친 요소가 계속 `opacity: 0`으로 남기 때문이다. 스크롤 핸들러가 매번 남은 목록을 훑는
방식이라 어느 방향으로 얼마나 뛰든 빠지는 요소가 없다.

또한 `.js-reveal` 클래스를 JS가 붙인 뒤에만 `opacity: 0`이 적용된다.
JS가 죽으면 본문은 처음부터 그냥 보인다.

### 8.3 캐러셀 화살표 배치

절대 위치 대신 flex-wrap 한 줄로 바꿨다. 마크업 중복 없이 `order`만 바꿔 배치를 전환한다.

- 데스크톱: `[이전] [패널] [다음]` 가로 배치, 아래에 도트
- 모바일: 패널이 `flex-basis: 100%`로 첫 줄을 차지하고, 아랫줄에 `[이전] [도트] [다음]`

원본의 화살표 SVG는 흰색 셰브론이라 흰 배경에서 보이지 않았다. 원본과 동일하게
회색 원형 버튼 위에 흰 셰브론을 얹는 형태로 인라인 SVG를 새로 그렸다.

## 9. 남은 이슈

- 없음. 데스크톱·태블릿·모바일 3구간 모두 정상 동작한다.
- 카피는 **데스크톱 기준으로 통일**했다. 원본은 브레이크포인트마다 카피가 미묘하게 다르다.
  데스크톱 `고등 정보` vs 모바일 `중등 정보`, 칩 `…교실 👍` vs `…교실!` 등인데 원본 자체의 불일치로 판단된다.
- **의도적으로 원본과 다른 부분**: 해결 섹션 일러스트 부유, AI 말풍선 띠 마퀴, 맞춤학습 원형 회전 배지를
  정지 상태로 두었다. 레이아웃·타이포·컬러·섹션 구조는 원본 그대로다.
